# Mbo–Ngo Place Name Atlas

An interactive map of populated places in Africa, Asia and Europe whose names contain one of 12 letter groups: MBO, MBU, MGBO, MGBU, MGO, MGU, NBO, NBU, NGBO, NGBU, NGO, NGU.

**View the map:** https://oxforder01.github.io/mbo-ngo-place-name-atlas/

78,728 matching places in 163 countries and territories.
